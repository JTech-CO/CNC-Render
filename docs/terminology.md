# CNC Render 표준 용어집

상태: M0 기준 규범 문서  
적용 범위: 한국어·영어 UI, 도움말, 튜토리얼, 진단, 보고서, 공개 스키마 설명

이 문서는 기술 백서 v1.0의 도메인 모델·G-code·시뮬레이션 정의와 디자인 백서 v1.0 §5.9의 문구 정책을 하나의 용어 기준으로 정리한다. 한국어 UI에서는 **표준 한국어** 열을 사용하고, 영어 UI에서는 **표준 영어** 열을 사용한다.

## 1. 표기 원칙

1. 한국어 UI의 기능명과 문장은 한국어를 기본으로 한다. 학습상 필요한 전문 용어는 문서에서 처음 등장할 때만 `한국어 (English)` 형식으로 병기한다.
2. 버튼, 탭, 필드 라벨 안에서 한국어와 영어를 임의로 섞지 않는다. 단, `G-code`, `CNC`, `CAD`, `TCP`, `SDF`, 축 이름과 단위 기호처럼 업계에서 식별자로 쓰는 표기는 유지한다.
3. TypeScript/Rust 식별자와 직렬화 필드명은 영어로 작성할 수 있다. 코드 식별자를 그대로 사용자용 한국어 라벨로 노출하지 않는다.
4. 약어는 첫 등장 시 전체 명칭을 함께 쓴다. 예: `재료 제거율 (Material Removal Rate, MRR)`.
5. 수치에는 단위를 표시한다. 표시 단위와 내부 계산 단위를 구분하며, 내부 길이 단위는 기술 백서에 따라 `mm`를 사용한다.
6. 정확도 등급과 근사 여부를 숨기지 않는다. `안전함`, `완벽함`, `실기계와 동일함`처럼 보증으로 오해될 표현은 사용하지 않는다.

## 2. 기계·가공 기본 용어

| 표준 한국어 | 표준 영어 | 정의 및 사용 규칙 |
|---|---|---|
| 컴퓨터 수치 제어 (CNC) | Computer Numerical Control (CNC) | 수치 명령으로 공작기계의 축·주축·보조 기능을 제어하는 방식. 제품명 외에는 첫 등장 후 `CNC`로 줄여 쓸 수 있다. |
| CNC 공작기계 | CNC machine tool | CNC로 제어되는 가공 장비. 문맥이 분명한 뒤에는 `공작기계` 또는 `기계`로 줄인다. |
| 밀링 | Milling | 회전 공구가 소재에서 재료를 제거하는 가공 방식. 기계 명칭인 `밀링 머신`과 구분한다. |
| 선삭 | Turning | 회전하는 공작물에 선반 공구를 접촉시켜 재료를 제거하는 가공 방식. |
| CNC 선반 | CNC lathe | 주로 선삭을 수행하는 CNC 공작기계. `선삭`은 공정, `선반`은 기계를 뜻한다. |
| 소재 | Stock | 가공 전 또는 가공 중 재료 제거 상태를 표현하는 원재료 모델. 코드의 `Stock`에 대응한다. |
| 공작물 | Workpiece | 기계에 고정되어 가공되는 실제 대상. 문맥에 따라 소재와 중간 가공 형상을 포함하는 상위 개념이다. |
| 목표 형상 | Target geometry | 공정이 도달해야 하는 의도된 최종 형상. 현재 소재 형상과 비교한다. |
| 고정구 | Fixture | 공작물을 위치 결정하고 고정하는 장치. 척, 바이스, 클램프 등을 포함할 수 있다. |
| 척 | Chuck | 선반 등에서 공작물을 파지하는 고정 장치. |
| 터릿 | Turret | 여러 선반 공구를 장착하고 인덱싱하는 공구대. |
| 심압대 | Tailstock | 선반에서 긴 공작물을 지지하거나 드릴 작업을 보조하는 장치. |
| 주축 | Spindle | 공구 또는 공작물을 회전시키는 기계 구성 요소. |
| 축 | Axis | 기계의 제어 가능한 직선 또는 회전 운동 자유도. |
| 직선축 | Linear axis | 직선 이동을 수행하는 축. 일반적으로 X, Y, Z를 사용한다. |
| 회전축 | Rotary axis | 회전 이동을 수행하는 축. 일반적으로 X, Y, Z축 둘레 회전에 A, B, C를 사용한다. |
| 기계 정의 | Machine definition | 운동학 트리, 축, 주축, 작업 영역, 한계, 모델 자산과 충돌 그룹을 포함하는 기계 데이터. 코드의 `MachineDefinition`에 대응한다. |
| 운동학 트리 | Kinematic tree | 기계 부품과 축의 부모-자식 변환 관계를 나타내는 계층 구조. |
| 작업 영역 | Work envelope | 기계가 유효하게 도달할 수 있는 위치·자세 범위. |
| 축 한계 | Axis limit | 각 축이 허용하는 최소·최대 위치와 속도·가속도 제한. |
| 원점 복귀 위치 | Home position | 기계가 기준을 설정하기 위해 복귀하는 축별 기준 위치. |
| 기계 좌표계 | Machine coordinate system | 기계 원점을 기준으로 정의한 고정 좌표계. |
| 작업 좌표계 | Work coordinate system (WCS) | 공작물 또는 가공 설정을 기준으로 정의한 좌표계. |
| 작업 좌표 오프셋 | Work offset | 기계 좌표계에서 작업 좌표계 원점으로의 변환. G54~G59 등을 포함한다. |
| 순기구학 | Forward kinematics | 주어진 축 값에서 공구 끝점과 자세를 계산하는 과정. |
| 역기구학 | Inverse kinematics | 목표 공구 끝점과 자세에서 가능한 기계 축 값을 계산하는 과정. |
| 공구 중심점 | Tool Center Point (TCP) | 공구 경로와 자세 계산의 기준이 되는 공구 끝 기준점. |
| 3축 가공 | 3-axis machining | 주로 X/Y/Z 직선축을 동시에 사용해 가공하는 방식. |
| 3+2축 가공 | 3+2-axis machining | 회전축으로 자세를 먼저 고정한 뒤 3축 경로를 수행하는 위치 결정식 5축 가공. |
| 동시 5축 가공 | Simultaneous 5-axis machining | 직선축과 회전축을 공구 경로 중 동시에 보간하는 가공. |

## 3. 공구·공정·절삭 조건

| 표준 한국어 | 표준 영어 | 정의 및 사용 규칙 |
|---|---|---|
| 공구 | Tool | 가공에 사용하는 절삭 또는 측정 도구의 일반 명칭. |
| 공구 어셈블리 | Tool assembly | 절삭부, 섕크, 공구 홀더와 게이지 길이를 합친 시뮬레이션 단위. 코드의 `ToolAssembly`에 대응한다. |
| 절삭부 | Cutter | 공구에서 재료 제거가 허용되는 부분. 비절삭부와 충돌 의미가 다르다. |
| 섕크 | Shank | 절삭부 뒤쪽의 비절삭 공구 몸체. 소재와 접촉하면 보통 충돌로 판정한다. |
| 공구 홀더 | Tool holder | 공구를 주축 또는 터릿에 연결하는 구성 요소. 처음부터 `홀더`만 쓰지 않는다. |
| 게이지 길이 | Gauge length | 기준면에서 공구 끝까지 측정한 공구 어셈블리 길이. |
| 가공 설정 | Setup | 공작물 고정, 좌표계, 기계·고정구 배치를 묶은 작업 조건. |
| 공정 | Operation | 공구, 전략, 파라미터와 목표 형상을 묶은 하나의 가공 작업. 코드의 `Operation`에 대응한다. |
| 공구 교환 | Tool change | 현재 공구를 다른 공구로 바꾸는 기계 동작. |
| 공구 길이 보정 | Tool length compensation | 공구 길이 차이를 좌표 계산에 반영하는 기능. G43/G49 등을 포함한다. |
| 공구 반경 보정 | Cutter radius compensation | 공구 반경만큼 프로그램 경로를 좌우로 보정하는 기능. G40/G41/G42 등을 포함한다. |
| 급속 이송 | Rapid move | 절삭을 목적으로 하지 않는 고속 위치 이동. 일반적으로 G0에 대응한다. |
| 절삭 이송 | Cutting feed | 공구가 재료를 제거하면서 이동하는 동작. |
| 이송 | Feed | 축 또는 공구의 진행을 뜻하는 일반 개념. 속도 값은 `이송 속도`라고 쓴다. |
| 이송 속도 | Feed rate | 단위 시간당 이송 거리. 일반적인 분당 이송은 `mm/min`으로 표시한다. |
| 회전당 이송 | Feed per revolution | 주축 1회전당 이송 거리. 기호 `fn`, 단위 `mm/rev`. |
| 날당 이송 | Feed per tooth | 공구 날 1개가 통과할 때의 이송 거리. 기호 `fz`, 단위 `mm/tooth`. |
| 주축 회전수 | Spindle speed | 주축의 분당 회전수. 단위 `rpm`; 라벨을 `rpm`만으로 쓰지 않는다. |
| 절삭 속도 | Cutting speed | 절삭날과 공작물 사이의 원주 방향 상대 속도. 기호 `Vc`, 단위 `m/min`. 주축 회전수와 다른 값이다. |
| 절삭 깊이 | Depth of cut | 공구축 방향 절입 깊이. 기호 `ap`, 단위 `mm`. |
| 절삭 폭 | Width of cut | 공구 반경 방향 절입 폭. 기호 `ae`, 단위 `mm`. |
| 횡방향 간격 | Stepover | 인접한 공구 경로 사이의 횡방향 간격. 필요하면 문서 첫 등장에만 `(Stepover)`를 병기한다. |
| 진입 | Lead-in | 본 절삭 구간으로 들어가기 위한 연결 이동. |
| 이탈 | Lead-out | 본 절삭 구간에서 빠져나오기 위한 연결 이동. |
| 일시 정지 | Dwell | 지정된 시간 동안 축 이동을 멈추는 명령. |
| 고정 사이클 | Canned cycle | 드릴링처럼 반복되는 동작을 하나의 G-code 사이클로 표현한 기능. |
| 재료 제거율 (MRR) | Material Removal Rate (MRR) | 단위 시간당 제거되는 재료 부피. 계산 결과에는 사용한 단위를 함께 표시한다. |
| 절삭력 | Cutting force | 절삭 과정에서 공구와 공작물에 작용하는 힘. 초기 제품에서는 근사값으로 표시한다. |
| 주축 동력 | Spindle power | 절삭에 필요한 주축 출력의 추정치. `kW` 등 단위를 표시한다. |
| 공구 마모 | Tool wear | 사용에 따라 공구 성능과 형상이 저하되는 현상. 시뮬레이션 값은 위험도 또는 근사치다. |
| 채터 | Chatter | 공구·공작물·기계계의 자려 진동. 확정 판정이 아니라 위험도로 표현한다. |

## 4. G-code와 공구 경로

| 표준 한국어 | 표준 영어 | 정의 및 사용 규칙 |
|---|---|---|
| G-code | G-code | CNC 동작을 기술하는 블록 기반 프로그램 언어. 하이픈을 포함한 표기를 사용한다. |
| G-code 프로그램 | G-code program | 원문, 방언, 공구표, 작업 좌표 오프셋과 진단을 포함하는 프로그램 데이터. |
| 블록 | Block | 한 줄 또는 하나의 논리 실행 단위로 해석되는 G-code 명령 묶음. |
| 워드 | Word | 주소 문자와 수치의 결합. 예: `X10.0`, `F250`. |
| 주소 | Address | G, X, F처럼 워드의 의미를 정하는 문자. |
| 모달 상태 | Modal state | 다음 블록에도 유지되는 평면, 단위, 좌표, 이송, 주축 등의 해석 상태. |
| 컨트롤러 방언 | Controller dialect | 제조사·제어기별 G-code 문법과 동작 차이. `Fanuc-like` 등의 프리셋은 완전 호환을 뜻하지 않는다. |
| 절대 좌표 방식 | Absolute positioning | 기준 원점으로부터의 절대 위치를 명령하는 방식. 일반적으로 G90. |
| 증분 좌표 방식 | Incremental positioning | 현재 위치로부터의 이동량을 명령하는 방식. 일반적으로 G91. |
| 평면 선택 | Plane selection | 원호와 일부 사이클의 기준 평면을 고르는 상태. G17/G18/G19. |
| 공구 경로 | Toolpath | 시간 또는 실행 순서에 따라 공구 끝점과 자세가 이동하는 경로. G-code 원문과 동일한 개념이 아니다. |
| 공구 경로 중간 표현 | Toolpath Intermediate Representation (Toolpath IR) | 파싱·모달 해석·정규화를 거친 기계 독립적 내부 이동 표현. 코드와 기술 문서에서는 `ToolpathIR`을 쓸 수 있다. |
| 경로 구간 | Toolpath segment | 직선, 원호, 헬릭스, 일시 정지 등 공구 경로를 구성하는 최소 실행 구간. |
| 원문 줄 매핑 | Source line map | 내부 경로 구간과 G-code 원문 줄의 대응 관계. 진단과 현재 실행 줄 표시의 근거다. |
| 진단 | Diagnostic | 오류, 경고, 참고와 관련 위치·원문 줄·수정 지침을 담은 구조화된 결과. |

## 5. 시뮬레이션·검증·형상 표현

| 표준 한국어 | 표준 영어 | 정의 및 사용 규칙 |
|---|---|---|
| 시뮬레이션 세션 | Simulation session | 프로젝트의 특정 실행 시간, 기계·공구 상태, 이벤트, 메트릭과 체크포인트 참조를 묶은 실행 상태. |
| 시뮬레이션 시간 | Simulation time | 재생 속도나 화면 프레임과 분리된 시뮬레이션의 논리 시간. |
| 체크포인트 | Checkpoint | 역방향 탐색이나 복원을 위해 저장한 특정 시점의 압축 상태. |
| 결정론적 재현 | Deterministic reproduction | 동일 입력·버전·설정·시드에서 허용 오차 안의 동일 결과를 다시 얻는 성질. |
| 재료 제거 | Material removal | 절삭부의 이동 부피를 소재 표현에 적용해 형상을 갱신하는 계산. 강체 물리와 구분한다. |
| 이동 체적 | Swept volume | 일정 시간 구간 동안 공구 형상이 지나가며 차지한 체적. |
| 잔여 소재 | Remaining stock | 특정 시점에 아직 제거되지 않고 남아 있는 소재 전체. |
| 잔삭 | Rest material | 목표 형상 기준으로 제거되어야 하지만 남은 재료. 일반적인 잔여 소재와 구분한다. |
| 과절삭 | Gouge / overcut | 목표 형상보다 더 많은 재료가 제거된 상태. 충돌과 별도 진단한다. |
| 충돌 | Collision | 공구 비절삭부, 홀더, 기계, 고정구 등이 허용되지 않게 접촉하거나 관통하는 사건. 정상적인 절삭부-소재 접촉과 구분한다. |
| 광역 충돌 검사 | Broad-phase collision detection | AABB·BVH 등으로 가능한 충돌 후보를 빠르게 줄이는 단계. |
| 정밀 충돌 검사 | Narrow-phase collision detection | 후보 형상 사이의 실제 접촉·관통을 더 정밀하게 판정하는 단계. |
| 덱셀 | Dexel | 한 방향 광선의 재료 구간을 저장하는 형상 표현. |
| 다중 덱셀 | Multi-dexel | 여러 축 방향의 덱셀 집합으로 소재 형상을 표현하는 방식. |
| 복셀 | Voxel | 3차원 격자의 부피 요소. 대형 복셀 배열은 UI 상태 저장소에 두지 않는다. |
| 희소 복셀 브릭 | Sparse voxel brick | 사용 중인 공간 블록만 할당하는 복셀 묶음. |
| 부호 거리장 (SDF) | Signed Distance Field (SDF) | 표면까지의 부호 있는 거리를 저장하는 필드 표현. |
| 표면 추출 | Surface extraction | 덱셀·복셀·SDF에서 렌더링 또는 내보내기용 표면 메시를 생성하는 과정. |
| 편차 | Deviation | 측정값과 목표값의 부호 있는 차이. 값, 단위, 기준을 함께 표시한다. |
| 측정 결과 | Measurement result | 측정 종류, 지점, 값, 단위, 목표와 편차를 포함하는 데이터. |
| 미리보기 | Preview | 빠른 응답과 낮은 자원 사용을 우선하는 해상도 프리셋. |
| 균형 | Balanced | 속도와 형상 품질의 균형을 맞춘 해상도 프리셋. |
| 정밀 | Precision | 더 높은 공간 해상도와 검증 품질을 우선하는 프리셋. 산업 인증을 뜻하지 않는다. |

## 9. 자주 혼동되는 개념

- **소재와 공작물**: `소재`는 재료 제거 엔진이 갱신하는 형상 데이터이고, `공작물`은 기계에 고정된 대상 전체를 가리킨다.
- **G-code와 공구 경로**: G-code는 입력 프로그램이고, 공구 경로는 모달 해석과 정규화 뒤 얻는 이동 결과다.
- **주축 회전수와 절삭 속도**: 주축 회전수는 `rpm`, 절삭 속도는 공구·공작물 직경을 반영한 `m/min` 물리량이다.
- **이송 속도와 회전당·날당 이송**: `mm/min`, `mm/rev`, `mm/tooth`는 서로 다른 값이므로 단위 없는 `이송` 필드를 만들지 않는다.
- **정상 절삭과 충돌**: 절삭부-소재 접촉은 정상 절삭일 수 있지만, 섕크·공구 홀더·고정구·기계 부품의 접촉은 충돌이다.
- **과절삭과 충돌**: 과절삭은 목표 형상보다 재료를 더 제거한 결과이고, 충돌은 허용되지 않은 객체 접촉 사건이다. 둘은 동시에 발생할 수 있으나 별도로 보고한다.
- **시뮬레이션과 렌더링**: 시뮬레이션은 기계·공구·소재 상태의 기준 결과를 계산하고, 렌더링은 그 결과를 시각화한다. 화면 프레임을 계산 결과의 기준으로 삼지 않는다.
- **정밀 프리셋과 산업 검증**: `정밀` 또는 S2는 더 높은 시뮬레이션 품질을 뜻할 뿐 V1 산업 검증을 뜻하지 않는다.

## 10. 변경 절차

새 용어를 추가하거나 표준 표기를 바꿀 때는 한국어·영어·코드 식별자의 대응, 기존 저장 데이터와 번역 키의 영향, 튜토리얼 및 진단 문구의 마이그레이션을 함께 검토한다. 의미가 바뀌는 변경은 관련 ADR 또는 스키마 버전 변경으로 기록한다.
