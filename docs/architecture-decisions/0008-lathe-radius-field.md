# ADR-0008: Z축 정수 반경 필드로 선반 Stock을 표현한다

- 상태: Accepted
- 날짜: 2026-08-01
- 마일스톤: M6 — CNC 선반 반경 필드·대표 공정

## 맥락

M6는 원통 Stock의 단면, 외경, 테이퍼, 홈, 절단, 드릴과 보링을 브라우저에서
결정론적으로 재현해야 한다. 이 공정들은 회전 대칭이므로 M5의 2차원
Z-multi-dexel이나 전체 3차원 복셀을 그대로 사용하면 계산량과 메모리가
불필요하게 커진다. 동시에 외경·내경 절삭의 제거 방향, G96/G97 주축 계산,
척·회전축 제한, 저장·복원 해시를 TypeScript와 Rust에서 동일하게 검증해야
한다.

## 결정

1. 선반 Stock은 canonical Z축과 동축인 회전체로 해석한다. Stock transform의
   위치는 회전축 중심과 축방향 중심을 정하며 회전은 M6에서 허용하지 않는다.
2. Z축을 `resolutionMm` 셀로 나누고 각 셀에 `outerRadiusLayers`와
   `innerRadiusLayers` 두 개의 `Uint32` 정수 값을 저장한다. 실제 반경은
   레이어와 해상도의 곱이며 초기 원통 반경에서만 마지막 부분 셀을 clamp한다.
3. 외경·단면·테이퍼·홈·절단은 외경 레이어를 감소시키고, 드릴·보링은 내경
   레이어를 증가시킨다. 항상 `0 <= inner <= outer <= initial`을 유지하며 같은
   또는 덜 공격적인 절삭은 무변경 결과를 반환한다.
4. Preview, Balanced, Precision은 Stock 기본 해상도에 각각 2×, 1×, 0.5×를
   적용한다. 목표 프로파일과의 반경 오차는 유효 셀 크기 이하로 검증한다.
5. G96은 `rpm = 1000 * Vc / (pi * D)`, G97은 지령 RPM을 사용한다. 결과는
   기계와 공구 최대 RPM 중 작은 값에서 clamp하며 요청값과 유효값을 함께
   반환한다.
6. 공구 끝 X가 회전축의 반대편으로 넘어가거나 Z가 설정된 척 파지 영역에
   들어오면 재료 제거와 별개의 선반 제한영역 충돌로 보고한다.
7. Profile hash는 버전, seed, preset, 해상도, 축 경계, 초기 반경, 셀 수,
   외경·내경 레이어 배열을 canonical JSON으로 만든 뒤 SHA-256으로 계산한다.
   저장 snapshot은 같은 레이어 배열과 revision을 보존하며 복원 후 동일 해시와
   측정을 내야 한다.
8. 렌더러는 축방향 셀마다 고정된 회전 세그먼트 BufferGeometry를 한 번
   할당한다. 변경 셀만 다시 쓰고 GPU update range를 부분 갱신한다. WebGPU와
   WebGL 2는 같은 CPU/WASM profile patch를 소비하며 WebGL 2에는 compute 기반
   표면 재구성이 없다는 차이를 유지한다.

## 거부한 대안

- 전체 XZ bitmap: 회전 대칭 공정에서 빈 공간까지 저장하고 내·외경 단조 규칙을
  불명확하게 만든다.
- 삼각형 메시 CSG: 시각 결과에 계산 상태와 해시를 종속시키고 해상도별 반경
  오차를 직접 검증하기 어렵다.
- 3차원 dense voxel 또는 M5 희소 브릭 재사용: 대표 2축 선반 공정에 필요한
  것보다 큰 메모리와 갱신 비용을 요구한다.
- Rapier 차집합: 충돌 엔진의 책임을 재료 제거까지 확장하므로 사용하지 않는다.
- 부동소수점 반경 배열을 해시: 런타임별 직렬화 차이를 결정론 경계로 끌어온다.

## 결과와 제한

- 변경 비용은 전체 3차원 Stock이 아니라 접촉한 Z 셀 수에 비례한다.
- 회전 대칭 외경·내경 프로파일, 축방향 직선/선형 테이퍼와 대표 홈·홀을 빠르게
  재현한다.
- M6는 Z축 동축 원통, 이상화된 인서트·드릴, 회전 대칭 형상만 지원한다. 나사산,
  편심 가공, 임의 프로파일 보간, 공구 코너의 실제 swept volume, 척 jaw 형상과
  절단 후 분리된 강체 동역학은 후속 범위다.
- 브라우저는 M7 Worker/WASM coordinator 전까지 TypeScript reference core를
  사용한다. 정확도 표시는 E2 교육용 근사이며 산업용 검증이나 실제 controller
  결과와 동일하지 않다.
