# CNC Render

CNC Render는 브라우저에서 CNC 가공을 살펴보고 대표 공정을 학습할 수 있는
오픈 소스 시뮬레이터입니다.

[웹에서 CNC Render 실행](https://jtech-co.github.io/CNC-Render/)

이 저장소는 **v0.9.0 Preview**이며 결과 정확도는 **E2 교육용 근사**입니다.
산업용 CAM 검증 도구나 실제 CNC 장비 제어기를 대신하지 않습니다.
아래는 현재 소스의 기능이며, 공개 데모에는 병합·배포된 변경만 반영됩니다.

## 주요 기능

- WebGPU 기반 3D 작업실과 기능이 명시된 WebGL 2 폴백
- G-code 해석부터 운동학, 충돌 검사, 재료 제거, 렌더링까지 이어지는
  전용 Worker/Rust/WASM 실행 경로
- 3축 밀링·외경 선삭·센터 드릴링의 공구 이동 및 점진적 소재 제거
- 실행·일시정지·계속·정지와 충돌 정지 상태 확인
- G-code 편집·원본 줄 단위 실행·브레이크포인트와 코드/진단/3D 위치 연결
- 평면 밀링·외경 선삭·드릴링의 5단계 실습, 측정 기반 채점과 복구 안내
- 밀링 샌드박스 Operation 생성·편집, 소재 크기·X/Y 절삭 방향 선택과 로컬 저장
- 거리·직경·반경·각도·깊이·벽 두께 측정 및 mm/in·deg/rad 표시 전환
- 실제 Stock과 목표의 Overlay·Split·Heatmap 비교, JSON·CSV·인쇄 HTML 리포트
- 키보드 탐색, 도움말 대화상자, 200% 확대를 고려한 라이트모드 UI

## 사용 방법

1. 위 실행 링크를 데스크톱 브라우저에서 엽니다.
2. 오른쪽 검사기에서 **3축 밀링**, **외경 선삭** 또는 **센터 드릴링**을 선택합니다.
3. 상단의 **실행**을 누르고 공구 위치와 소재 형상 변화를 확인합니다.
4. **코드**에서 지원되는 G-code를 편집하고 실행합니다. 편집기에서 F9는 중단점,
   F10은 줄 실행입니다. 실행 중에는 편집이 잠기며 정지 후 수정할 수 있습니다.
5. **학습**에서 실습을 선택하거나 **샌드박스**에서 밀링 설정을 적용합니다.
6. **결과 → 현재 Stock 비교**로 편차를 확인하고 리포트를 저장합니다.

카메라는 드래그로 회전·이동하고 휠로 확대하거나 축소할 수 있습니다.

WebGPU를 사용할 수 없으면 WebGL 2로 전환됩니다. 최신 데스크톱 Chrome 또는
Edge 사용을 권장합니다.

## 현재 제한

- G-code는 `common-v1` 지원 범위에서 실행합니다. 미지원 명령은 원본 줄과 함께
  명시적으로 거부하며 자동 변환하지 않습니다. 파일 가져오기와 MDI는 제공하지 않습니다.
- 편집 코드는 세션 한정이며 새로고침 전에 별도로 복사해야 합니다. 코드 탭의 상단
  프로젝트 저장은 지원하지 않습니다. 다른 영역의 상단 저장은 선택한 대표 공정
  (샌드박스에서는 확정 Operation)을 재실행해 저장합니다. 편집 실행의 결과는
  **결과** 영역에서 리포트로 내보낼 수 있습니다.
- 샌드박스는 교육용 VMC·Aluminum 6061·Ø20 mm 공구와 두 직육면체 Stock preset으로
  제한됩니다. 임의 모델·기계·공구 라이브러리를 제공하지 않습니다.
- 비교 목표는 대표 공정별로 작성된 형상입니다. 임의 CAD 목표 가져오기, 형상 자동 인식,
  최소 벽 두께 탐색은 제공하지 않습니다. 측정의 기준점·기준면은 직접 지정합니다.
- 밀링 8 mm 격자·선반 1 mm layer의 교육용 Stock 근사이며 작은 형상의 정밀도를
  보증하지 않습니다. 큰 비교 지도는 일부 표본만 표시하되 통계는 전체 데이터를 사용합니다.
- 불러온 Stock은 현재 실행 세션과 다를 수 있으므로 다시 실행한 뒤 비교합니다.
- 시뮬레이션은 결정론적 교육용 근사이며 실제 기계의 제어기, 공구 처짐,
  열 변형과 모든 CAM 방언을 재현하지 않습니다.
- WebGL 2는 동일한 실행 계약을 사용하지만 WebGPU보다 표면 해상도와 GPU 갱신
  범위가 제한됩니다.

지원되는 G-code와 명시적으로 거부되는 기능은
[G-code 지원 매트릭스](docs/gcode-support-matrix.md)에서 확인할 수 있습니다.

## 로컬 개발

Node.js **24.18.0**, pnpm **11.5.3**, Rust **1.97.1**을 사용합니다.

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm verify
pnpm test:pages
```
